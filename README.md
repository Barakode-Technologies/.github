## Our Top Projects

### **AI & Machine Learning**

We believe in the power of **AI** to transform the world. Check out our top AI projects that blend **innovation** with **technology**.

#### 1. **PDFBot**

* A next-gen **AI-powered chatbot** solution that uses **Retrieval-Augmented Generation (RAG)**. Built for **multi-tenancy**, it offers flexible, scalable, and powerful chatbot solutions for analyzing and interacting with documents.

#### 2. **Medical Vision AI**

* **Medical AI** at its best. This **UNET-based** model detects **glaucoma** from medical images, showing how AI can make a critical difference in healthcare diagnostics.

#### 3. **Signature Recognition AI**

* Dive into **computer vision** with **CNNs** for **signature recognition**. A robust project that showcases the potential of deep learning in secure authentication systems.

#### 4. **Hallucination Detection**

* **Text classification** for **hallucination detection** in AI responses, built using **logistic regression**. An essential tool for ensuring more accurate and reliable AI outputs.

#### 5. **Face-to-Sketch CycleGAN**

* Watch how **CycleGANs** transform **sketches** into **realistic faces**! A fascinating look into the world of **image-to-image translation** using generative adversarial networks.

#### 6. **Custom Neural Network (C++)**

* A hands-on implementation of a neural network with **forward** and **backward propagation** in **C++**. A foundational project for understanding deep learning architecture from scratch.
